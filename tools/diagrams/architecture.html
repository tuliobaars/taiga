Shiny

run_app() · <pkg>_app()
  • assets via one htmlDependency
  • payload from the server, without secrets
  • protocol: input$<id>_msg ↔ '<id>-msg'
  • grading, persistence, resume codes

Quarto

export_quarto() · *_quarto_block()
  • raw-HTML block or include files
  • payload embedded at render
  • embed-resources: true
  • the author's markdown around the tool

Standalone HTML

export_html()
  • everything inline in one file
  • fonts as data URIs
  • payload embedded at export
  • offline, e-mailable, archivable
